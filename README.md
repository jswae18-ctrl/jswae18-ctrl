# Hey, I'm Jason

I'm a C++ developer interested in the parts of software where you have to understand what's actually happening underneath the abstractions.

Most of my current work is going into **Kinetic Aura Dynamics**, built around a custom C++/DirectX 11 engine I've been developing from the ground up. Working on it has pushed me deeper into graphics programming, HLSL, rendering systems, cameras, input, runtime tooling, ownership, and engine architecture.

I also have a strong interest in **low-level systems and security research**. I enjoy learning about memory, native binaries, reverse engineering, debugging, Windows internals, and how software behaves at a lower level than the normal application layer.

Those interests overlap more than they might look like they do. Whether I'm tracing data through a renderer or trying to understand what a compiled program is doing in memory, the part I enjoy most is breaking a system down until I can actually explain how it works.

## What I'm Working On

### Kinetic Aura Dynamics

My main project right now is **AuraDynamicsEngine**, a custom DirectX 11 engine written in C++.

Current work includes:

- procedural sphere geometry
- custom HLSL rendering
- Sun-driven Earth lighting
- normal mapping and ocean specular
- night-side city lights
- animated clouds
- orbital movement and rotation
- free-flight and moving-target camera systems
- custom keyboard and mouse input
- runtime HUD/editor tooling
- the early AuraPlatform foundation

The public repository is a working development checkpoint with source, tests, screenshots, and engine demos.

## How I Learn

I care more about understanding why something works than just getting code to compile.

I use documentation, debugging, experimentation, and AI-assisted tools while learning, but I try to trace unfamiliar code until I can explain the ownership, data flow, lifetime, and reason the system is structured the way it is.

If something makes the project worse or I can't justify why it belongs, I don't want to keep it just because it looks more advanced.
